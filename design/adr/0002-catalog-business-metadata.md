# ADR 0002: カタログのビジネスメタデータをエージェントに渡す

- Status: Accepted
- Date: 2026-09-25

## Context

エージェントはテーブル選択と SQL 組み立てにカラム名と型しか使っていなかった。SageMaker Catalog に書かれたリスティングの説明文・ビジネス用語・メタデータフォーム・カラムのビジネス名は `GetListing` の応答に載っているのに、`catalog_detail` は `GlueTableForm` / `S3ObjectCollectionForm` 以外を捨てていた。カラム単位のメタデータ、用語の定義本文、フォームの定義は取得する API を呼んでいなかった。

読み取りの認可の境界は `data-access-control.md`「カタログ読み取りの認可」にある。

## Decision

1. 用語の定義とフォームの定義は新しいツール `catalog_definition` で返す。`catalog_detail` は用語 ID・名前・短い説明とフォーム名までを返す
2. カラム単位のメタデータは `catalog_detail` のたびに取得する。ビジネス名・説明・用語はリスティングの `ColumnBusinessMetadataForm` から、カラムに付けたフォームは `BatchGetAttributesMetadata`（`entityType=LISTING`）から取る
3. リスティングのフォームは除外リストでシステム管理のものを除き、残りをそのまま返す
4. 取得の一部が失敗しても、スキーマと取得できた分を返し、失敗した項目を `unavailable` に示す

## Alternatives

| 判断 | 採った案             | 却下した案                          | 却下の理由                                                                                                                                                                                  |
| ---- | -------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 定義を別ツールで返す | `catalog_detail` で定義まで展開する | 用語 n 個・フォーム m 個で n+m 回の追加呼び出しが、定義を使わない SQL 作成でも毎回走る                                                                                                      |
| 2    | 毎回取得する         | 引数を付けたときだけ取得する        | LLM が引数を付け忘れるとカラムの意味が落ちる。ビジネス名・説明・用語はリスティングから追加呼び出し無しで取れるので、毎回取得のコストはカラムのフォーム取得（5 カラムごとに 1 回）に限られる |
| 3    | 除外リスト           | 許可リスト                          | カスタムフォームは名前が事前に分からず、許可リストでは返せない                                                                                                                              |

## Consequences

- AWS が新しいシステム管理のフォームを足すと、除外リストを直すまで `catalog_detail` の応答に混ざる
- `BatchGetAttributesMetadata` は 1 回 5 カラムまでなので、N カラムのテーブルで ceil(N/5) 回呼ぶ（同時実行は 4 まで）。`cost-estimate.md` の DataZone API 呼び出し数はこの分増える
- カタログの文字列はデータプロデューサーが自由に書け、モデルのコンテキストに入る。扱いは `data-access-control.md`「カタログ内容の信頼境界」
